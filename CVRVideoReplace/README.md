**Replaces the blank video file with a setted up video/gif/png.**

This mod idea is because when you currently import a mp3 file into the video player, it is just showing the blank screen or the last image it played from the last video.
This mod will allow you to set a video file, a gif or a png that is then getting shown.

To avoid any conflicts it should first test, if the video player has a audio only stream.

To use it you can just add the mod to the Unity project, set the video script component and then the file, that you want to use (it needs to be part of the Unity project).
Also you need to place that mod in your current mods folder, since scripting is only possible over lua and not everyone has that currently.
